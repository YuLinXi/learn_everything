# Mission: 接手 Java Web 后端开发

## Why

我是一名前端开发工程师，擅长 TypeScript 和 React，希望补齐 Java Web 后端能力，成为能独立承担前后端需求的全栈开发者。学习以尽快接手公司实际后端开发工作为目标，优先覆盖 `projects/` 中工程使用的能力。

## Success looks like

- 沿真实请求定位 Controller、接口、业务实现、DAO/查询引擎和返回结果，解释数据与权限边界。
- 独立实现一个含持久化、参数校验、事务、鉴权/数据归属、错误处理的小需求，完成 React 联调。
- 用当次测试、日志和断点定位问题；提供可复核的代码、测试、测试环境验证与评审证据。
- 能说明构建、配置、数据库变更、上线验证和回滚方式，并在需求变化时独立修改。

## Constraints

- JavaGuide 为主教材，公司源码为实践依据；按限定范围阅读，以高 ROI 安排先后。
- 已有 TS/React 能力为用户自述；Java/SQL/Spring 起点待实际评估。
- 每周可投入时间尚未指定；路线用每周 10 小时作为可调整估算。
- 默认自主阅读与连续实践，导师负责答疑、单题掌握检查和记录。
- 以本地 Markdown 为正式进度来源；阅读、提示、AI 辅助、独立作答和实际运行分别记账。

## Out of scope

- 首阶段暂缓完整面试八股、深层框架源码和全部中间件，按目标需求补充。
- 本次交付学习路线及记录机制；公司代码实际改动、部署与发布安排在后续具体练习中。
