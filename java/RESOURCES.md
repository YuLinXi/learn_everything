## Gaps

- 公司 `udc-parent`、`boot` 父 POM 源码、具体 Spring Boot/MyBatis 版本、完整基础 starter 实现不在当前四个仓库中；本机对应父 POM 缓存本次未找到。
- 公司运行数据库/方言、认证上下文、错误包装序列化、CI 发布与回滚规范需通过依赖和环境验证。
- JavaGuide 的单测文章侧重方法论；JUnit/MockMvc/Mockito 的具体 API 在开始练习时按项目实际版本从官方文档补查。
- `EnumCacheUtils` 中可见 Redis 调用，不能据此推断全部工程都必须部署 Redis；MQ、注册中心等按目标需求及真实调用补查。
