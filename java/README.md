开始方式：在终端/当前对话中说“开始学习”，导师直接呈现有明确范围的学习块，并按 [章节作业规范](practice/README.md#章节作业规范) 组织材料。关系图和配置对照由导师生成讲解；代码保存后告知完成，导师读取并核验。简短理解题可直接在对话回答，由导师归档。后续说“继续学习”“记录当前学习进度”“今天学习结束”即可按台账续接。

讲解默认在终端/当前对话中呈现，已有 HTML 课程与速查保留为可选材料；本地 Markdown 保存状态。打开材料或生成作业不会自动增加掌握进度。无需安装新服务或接入 DeepTutor，即可持续记录。

核心路线估算 78–110 小时。G1 是独立 Java 小程序，G2 是可运行数据库 API，G3 是公司小需求的实现、测试环境验证和评审；完整标准见路线。当前公司工程只完成静态阅读，未构建或启动。
