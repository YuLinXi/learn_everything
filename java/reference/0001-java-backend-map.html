TS 经验 → Java 中要核对的差异

已有经验Java 中的落点最常见边界
interface 约定形状接口声明能力，类显式 implementsJava 接口可参与运行时类型判断；泛型参数通常擦除。不要直接套用 TS 的结构兼容规则。
对象与函数类、实例、构造器、实例/静态方法接口声明类型与实际对象类型可不同；访问范围和重写规则需由编译器验证。
numberint / long / double / BigDecimal金额选择与舍入需明确；long ID 返回 JS 可能越过安全整数范围。
Array / MapList / Set / Map关注泛型、空值、有序性、重复键与 equals/hashCode；Stream 是处理方式。
undefined / nullnull 与可空包装类型基本类型不承载 null；拆箱可能抛空指针。Optional 并不自动解决所有空值问题。
异步与事件循环请求线程、共享 Bean、线程池单例中的可变字段可能跨请求共享；请求数据优先使用局部变量。
前端表单校验后端绑定、校验、授权和数据库约束用户可绕过 UI；数据归属、租户与业务唯一性由服务端验证。

依据：对象与接口、泛型、金额、Spring Bean、服务端校验。

本课程统一用语

术语在课程中的含义
ControllerHTTP 入口，负责路由、参数绑定与调用下层；先看请求与响应契约。
AppService公司应用服务层的命名/注解，按当前源码观察其编排职责；具体拦截行为另查公司实现。
Service业务服务。公司分层不完全一致，最终职责以代码和领域文档为准。
DAO / Mapper数据访问接口；本工程常见 BaseMybatisDao 封装。查询引擎另有执行入口。
DTO / EntityDTO 用于传递数据；持久化 Entity 对应存储模型。公司“实体域”还可能指元数据业务对象，需看上下文。
Bean / DISpring 管理的对象 / 依赖注入；源码实现关系与运行时选中的对象分别核验。
事务将相关数据库操作组织成有明确提交/回滚边界的工作单元，不能替代权限或接口幂等。
验收 / 复查验收看当次独立能力；复查看间隔之后能否再次正确使用。两者分开记录。

依据：IoC/DI、MyBatis、事务与公司源码。

接手接口时的五个定位动作

  1. 从前端请求找到 Controller 的路由与方法，确认输入和响应。
  2. 沿 import / IDE 跳转确认完整包名，再找接口对应实现。
  3. 追踪校验、身份/数据权限、业务分支、事务与持久化边界。
  4. 取得真实 SQL、日志或调试证据；标出尚未进入的外部组件。
  5. 用正常、边界与失败路径验证，记录实际运行结果及需要的帮助。
