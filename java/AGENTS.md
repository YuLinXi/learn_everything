# 教学工作区

默认简洁中文。此目录用于 Java Web 学习；先完成用户当前明确授权的学习任务。

## 开始或继续学习

1. 读取 [MISSION.md](MISSION.md)、[PROGRESS.md](PROGRESS.md)、[NOTES.md](NOTES.md) 和相关 `learning-records/`，确定当前单元、已有证据和未回答问题。
2. 在 [ROADMAP.md](ROADMAP.md) 找到该单元的限定阅读、练习和验收；先给出一个可执行学习块。已有未回答题时优先恢复原题。
3. 每次只问一道闭卷/迁移题，等用户独立作答后反馈。生成代码、讲解或打开页面不构成用户独立掌握证据。
4. 源码关系图与配置对照由导师读取后生成并讲解；通过单道简短问题或代码实践检查理解，不布置手工画图、逐边抄录或批量配置填表作业。

## 记录与材料

- 用户要求记录进度或结束学习时，按 PROGRESS 的规则保存精确断点、证据、提示、未回答题和下一步；未回答题保持未评分。
- 设计作业、规定提交内容、查验或迁移作业前，读取 [章节作业规范](practice/README.md#章节作业规范)，落实学生产出与导师核验的分工，按章节目录和题号组织文件，保留用户原答案与证据分类。
- 创建 HTML 课件前读取 `assets/`，HTML 放 `lessons/NNNN-slug.html`，引用共享样式；复用术语和速查页。learning-record 只记录有依据的理解、误解修正或自述背景。
- 更改既定 mission 前与用户确认；路线的日常范围和顺序可按实际验收调整。
- 公司源码任务先读 [PROJECT_MAP.md](PROJECT_MAP.md) 和目标仓库自己的 AGENTS/领域入口，再核对当前分支、提交与源码。
- PROGRESS 是本工作区的正式状态；外部学习系统按用户明确要求同步。其他工作区的历史证据逐条复核后再引用。
