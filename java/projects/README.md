# 公司与参考工程

本目录存放用于 Java 学习、源码阅读和真实调用链实践的公司工程或其他参考工程。每个工程放在独立子目录中，使用它自己的 Git 仓库管理代码、分支和提交。

当前学习使用的工程包括 `udc`、`udc-common`、`boot-extend` 和 `cdp-report`；仓库关系、源码入口及学习用途见 [公司工程学习地图](../PROJECT_MAP.md)。

## 存放方式

```text
java/projects/
├── README.md       # 本说明，纳入学习空间版本管理
├── udc/            # 独立仓库，本地克隆
├── udc-common/     # 独立仓库，本地克隆
├── boot-extend/    # 独立仓库，本地克隆
└── cdp-report/     # 独立仓库，本地克隆
```

- 需要阅读某个工程时，从有权访问的代码托管平台将仓库克隆到本目录下；学习空间不会自动下载这些工程。
- 本目录除 `README.md` 外的所有内容均由根目录 `.gitignore` 忽略，不作为学习空间的源码或 Git 子模块提交。工程内的修改在各自仓库中管理。
- 自己编写的章节练习、测试和运行证据放在 [practice/](../practice/)，学习笔记和进度保存在 Java 学习目录中，便于随学习空间一起提交。
- 在新机器上克隆学习空间后，按需重新克隆参考工程，并核对当前分支、依赖和本机配置；具体操作遵循目标工程自己的说明。
