# Markdown 课件规范与索引

本文件是本工作区课件生成、呈现、目录、命名和内容结构的统一规范。沿用 teach 的教学工作区组织方式，原始课件使用 Markdown（`.md`）。

## 生成与会话呈现

1. 每次开始新的学习块，导师先在 `lessons/` 保存包含实际讲解与示例的原始课件，再开始讲授或布置该块练习。
2. 当前会话同时直接呈现本次课件的学习目标、限定阅读、讲解、示例及练习指引，并附课件链接；只给链接、文件路径或内容提纲不算完成教学呈现。
3. 课件较长时按学习块逐段呈现；闭卷或迁移题一次只出一道，等待用户独立作答后反馈。
4. 同一学习块续学、答疑或补充示例时，复用并更新原课件；已经讲过的正文无需每条回复重复粘贴。进入新的独立主题或下一学习块时再新建课件。
5. 结束本次讲解前，将实际新增的关键解释、修正和示例同步到原课件，使文件可以独立回看。课件文件与会话正文保持一致。
6. 生成课件或讲解不产生用户掌握证据；正式进度仍按 [PROGRESS.md](../PROGRESS.md) 记录。

## 存放目录与命名

- 课件目录固定为本工作区的 `lessons/`；本文件维护规则与索引。
- 文件名统一为 `NNNN-mMM-U-topic.md`，例如 `0001-m01-1-null-and-unboxing.md`。
- `NNNN` 是四位课件序号，从 `0001` 开始，按现有课件最大序号递增；它与 ROADMAP 的单元编号独立。
- `mMM-U` 对应学习单元：`M00.1 → m00-1`、`M01.2 → m01-2`。`topic` 使用简短英文小写单词，以连字符分隔。
- 一份课件聚焦一个学习块；同一单元可以有多份课件。续学更新原文件，已发布的编号和文件名保持稳定。
- 文档标题使用 `# MXX.Y · 本次主题`，正文顶部链接所属 ROADMAP 单元和对应章节作业。
- 新增课件后追加下方索引。按本次实际学习范围生成，无需提前批量生成整个路线的课件。
- 回补历史课件时继续追加序号，保留已发布课件的编号与文件名；索引按 ROADMAP 学习顺序展示。回补内容根据原会话、章节作业和学习记录整理，原题、用户答案与验收状态保留在原文件中。

```text
java/
├── lessons/
│   ├── README.md                            # 课件规范与索引
│   └── 0001-m01-1-null-and-unboxing.md       # 一个学习块的原始课件
├── practice/
│   └── practice/
│       └── m01_1/
│           ├── README.md                    # Q01、Q02……要求、答案与反馈
│           └── project/                     # 按需创建的可运行工程
├── PROGRESS.md                              # 正式状态与续学断点
└── learning-records/                        # 有依据的掌握与误解修正
```

## 内容结构

课件按以下结构组织；每节写本次所需的实际内容，避免空壳模板：

| 部分 | 必需内容 |
| --- | --- |
| 学习目标与范围 | 本次要获得的能力、适用场景、包括及暂缓的内容 |
| 限定阅读 | 原始资料直接链接、起止标题、包含与跳过的内容、阅读目的；必读资料以 JavaGuide 为主 |
| 核心讲解与示例 | 能独立回看的概念解释、最小示例、必要的 TS/React 类比及 Java 差异；复用既有术语和速查资料 |
| 本次练习 | 练习目标、操作入口及对应章节 README 的题号链接 |
| 验收与复习 | 要证明的能力和复习要点；具体问答及实际结果由章节作业与正式台账保存 |
| 资料与关联 | 补查依据、相关源码或速查材料，以及下一学习块的衔接 |

章节作业 README 保存完整题目、用户答案和验收反馈；课件链接到相应题号，避免在两处维护同一套作业正文。已有讲解迁入课件时，先备份、更新引用并核对题面及用户证据完整，遵循 [迁移与校验](../practice/README.md#迁移与校验)。

```markdown
# MXX.Y · 本次主题

所属单元：ROADMAP 对应单元的链接
对应作业：章节 README 及当前题号的链接

## 学习目标与范围
本次目标、应用场景与暂缓内容。

## 限定阅读
资料链接、起止标题、包含与跳过的内容及阅读目的。

## 核心讲解与示例
实际讲解、示例及必要的语言差异对照。

## 本次练习
练习目标与入口，链接章节 README 的具体题号。

## 验收与复习
要证明的能力及复习要点。

## 资料与关联
补查依据、相关材料与下一学习块的衔接。
```
